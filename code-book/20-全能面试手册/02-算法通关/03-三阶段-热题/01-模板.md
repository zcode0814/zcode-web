## 和为 k 的子数组

https://leetcode.cn/problems/subarray-sum-equals-k?envType=study-plan-v2&envId=top-100-liked

> 不满足单调性，不能用滑动窗口

```java
class Solution {
    public int subarraySum(int[] nums, int k) {
        // 前缀和
        int n = nums.length;
        int[] sum = new int[n + 1];
        for (int i = 0; i < n; i++) {
            sum[i + 1] = sum[i] + nums[i];
        }

        // 转为两数之和
        Map<Integer, Integer> map = new HashMap(n + 1,1); // 负载因子为 1，避免扩容
        int ans = 0;
        for (int i = 0; i < sum.length; i++) {
            ans += map.getOrDefault(sum[i] - k, 0);
            map.merge(sum[i], 1, Integer::sum); // key不存在，默认值 1，key 存在，+1
            // 扩展 map.merge(sum[i], 1, (oldVal, newVal) -> oldVal + 2);
        }

        return ans;
    }
}
```
